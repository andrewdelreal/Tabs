## Tabs Generator

This is my custom guitar tablature generator designed to help me as a newer player get more comfortable with the fretboard. This C# and XAML project provides a GUI to generate randomized catered tablature to help with sight reading and muscle memory.

### Key Features
- Generate random notes on a text view to produce text based tablature.
    - Can choose which strings and fret range to choose from.
- Can edit the randomized file or create an empty file to write down quick melodies or chords that may come to mind.
